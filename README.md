# Talad Chao AI Test

ชุดทดสอบสาธารณะของแอปสมุดขายสำหรับให้ AI หรือนักพัฒนาตรวจสอบหน้าจอและการทำงาน โดยแยกออกจากระบบใช้งานจริงทั้งหมด

## ความปลอดภัยของข้อมูล

- ลูกค้า สินค้า ยอดขาย รายจ่าย และเส้นทางทั้งหมดเป็นข้อมูลสมมติ
- ไม่มี PIN ร้าน ข้อมูลพร้อมเพย์ ข้อมูลลูกค้าจริง หรือโทเคนระบบ
- ไม่เชื่อมต่อฐานข้อมูล production
- ข้อมูลที่ทดลองกรอกจะเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น

## ทดลองใช้งาน

วิธีง่ายที่สุดคือดาวน์โหลด repository แล้วเปิดไฟล์ `talad-chao-ai-test.html` ด้วยเบราว์เซอร์สมัยใหม่

ตัวอย่างนี้รองรับการลงยอดขาย ประวัติลูกค้า ใบส่งของ สถานะชำระเงิน รายจ่าย กำไร–ต้นทุน การจัดลำดับเส้นทาง และการสำรอง/กู้คืนข้อมูลจำลอง

## โครงสร้าง

- `talad-chao-ai-test.html` — แอปทดสอบแบบไฟล์เดียว เปิดใช้งานได้ทันที
- `static-demo/` — ไฟล์ประกอบสำหรับนักพัฒนาที่ต้องการตรวจโครงสร้างตัวอย่าง
- `README-AI-TEST.md` — หมายเหตุจากชุดส่งมอบเดิม

## ข้อจำกัด

repository นี้เป็นชุดสำหรับตรวจและทดลองเท่านั้น ไม่ใช่ซอร์ส production และไม่ควรนำข้อมูลธุรกิจจริงมาใส่
